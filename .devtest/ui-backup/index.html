RACE YOUR FRIENDS

Host a room and send your friend the 5-letter code. They pick Join and type it in. Up to 8 drivers, the rest of the grid can be filled with AI.

Cars connect directly peer-to-peer. The public PeerJS server is only used to introduce the two computers. Everyone should run the same version of the game.

How To Play

DRIVING

W / ↑Throttle
S / ↓Brake · hold to reverse
SPACEHandbrake · flick it to start a drift
A D / ← →Steer
E / QShift up / down (manual)
CChange camera
RReset car to track
LRacing line: full / braking only / off
MMinimap zoom (satellite / street map in Options)
SlipstreamTuck in behind a car on a straight for extra speed
Pit laneDrive into the pit entry to box · the crew drives you in; pick tyres & repairs with the arrows
ESC / PPause
FToggle fullscreen

GAMEPAD

Left stickSteer
RTThrottle
LT / XBrake
A / ✕Handbrake
RB / LBShift up / down
YCamera · Back: reset · Start: pause
D-pad up / downRacing line toggle / minimap zoom

TRACK EDITOR

DRAWDrag to sketch a circuit loop
EDITDrag nodes · double-click road to add · DEL removes
SHIFTClick / drag-box to multi-select nodes
PROPSPlace scenery · Q/E rotate · right-click removes
ZONESDraw a line to spawn houses, shops, towers or trees along it
PAINTPaint grass onto the ground · [ ] brush size
ROADSDraw streets · they stop at the circuit's barriers
PROPSClick a building: drag to move · Q/E rotate · DEL remove
MAP tabSearch your town, trace real streets, import real buildings
ProfileDrag nodes in the elevation graph
Wheel / RMBZoom / pan the map
Ctrl+Z / YUndo / redo

Tip: raise one part of a crossing track 5m+ above the other and a bridge is built automatically.
